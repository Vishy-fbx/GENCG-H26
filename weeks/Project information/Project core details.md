
# Project idea

The initial project idea is to create a software that draws a painting within 75 lines of code.  The steps of creating is as follows:

1. The system selects a random painting from an array. It will use a random number generator, and the generator will simply select a number between 0 and 49(There will be 50 different paintings all from Pinterest and other painting platforms)

2. Based on the selected painting, the computer must try to draw the painting using a set of parameters and rules, which I will integrate. 

3. The computer can also use AI, but can only to guide the computer in creating the artwork and not creating the artwork using AI, otherwise the artwork would be flagged as AI. The AI can only give instructions and the computer just follows in creating the artwork.

4. One important rule is that the code can be 75 lines or lower
